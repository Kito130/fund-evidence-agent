# Public Data Profiles

- `demo_synthetic/` is the default deterministic profile. It contains no real
  fund performance, document, account, or investment data.
- `sample_public/` is reserved for narrowly bounded public excerpts only after a
  redistribution-rights review. It is intentionally absent in the current stage.

Complete PDFs, complete extracted text, private caches, and full derived research
tables are never included in the public repository.

See `DATA_MANIFEST.md` for the classification and publication rationale of every
included data and evaluation group.
