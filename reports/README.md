Files whose names begin with `phase6_`, `phase7_`, or `phase9_` are path-stable
compatibility records from the original build workflow. Their paths remain
unchanged because configuration files, run manifests, and hash checks refer to
them. They are not the public narrative and do not override the README or the
domain documents above. Any historical result must still be read with its
execution mode, data profile, and holdout boundary.

The bundled PDF and TeX report are retained as derived historical research
documentation. They do not include private source PDFs or complete extracted
text and do not turn the synthetic demo into a real-fund reproduction.
