# Reports and Evidence Map

The public-facing documentation is organized around external concepts rather
than internal phase numbers:

- [architecture.md](architecture.md): components, data contracts, runtime
  controls, and local deployment;
- [evaluation.md](evaluation.md): the named seven-suite deterministic offline
  evaluation and its exact scope;
- [limitations.md](limitations.md): synthetic-data, retrieval, Agent, and
  product boundaries;
- [demo_guide.md](demo_guide.md): a local walkthrough of the synthetic service.

The `phase6_*`, `phase7_*`, and `phase9_*` files are historical evidence
artifacts from the project build. They are not the primary navigation and do not
override the current README or the external-facing documents above. In
particular, any phase result must be read with its execution mode, data profile,
and holdout boundary.

The bundled PDF and TeX report are retained as derived research documentation.
They do not include the private source PDFs or complete extracted text and do
not turn the synthetic demo into a real-fund reproduction.
