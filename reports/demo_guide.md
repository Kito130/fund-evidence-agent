# 五分钟演示脚本

## 0:00--0:40 说明边界

- 系统名称：可追溯文档检索与模板化投研 Memo 系统。
- 默认完全合成数据；无网络、无 API Key、无云部署。
- 仓库不分发真实样例、真实摘录或完整 PDF。

## 0:40--1:50 页面一：基金与组合诊断

1. 运行 `streamlit run app.py`，确认数据模式为“合成演示（默认）”。
2. 展示累计净值、回撤和相关性。
3. 展示 C10、HHI10 与同报告期公开前十大持仓重合。
4. 强调不填充净值日历空档，不把公开前十大表述为完整持仓。

## 1:50--3:20 页面二：证据与 Memo

1. 保持“合成演示（默认）”。
2. 选择基金 `SYN001`、报告期 `2026Q2`，输入“市场震荡”。
3. 展示证据卡的 `doc_id`、PDF 物理页、`chunk_id`、来源 URL 和文本哈希。
4. 展示四段模板 Memo，并说明没有外部 LLM。

## 3:20--4:05 拒答

输入“请提供火星基地明天的天气和彩票号码。”，确认精确输出：

> 当前文档不足以回答该问题。

说明拒答由最低余弦分数和查询字符 gram 覆盖率共同控制。

## 4:05--4:40 评测协议

- 32 个合成离线案例覆盖路由、数值、引用、拒答和注入；
- 评测使用确定性 mock，不调用真实模型；
- 32/32 只说明固定软件契约通过，不宣称 LLM 泛化。

## 4:40--5:00 收束

打开 `reports/research_report.pdf` 和 `reports/resume_evidence_map.md`，
展示每个简历数字如何追溯到结果表、审计 JSON、脚本、配置和数据版本。
