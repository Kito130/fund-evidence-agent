\section{执行摘要}

本项目把基金净值与公开持仓诊断、官方季度报告检索、物理页级引用、模板化
Memo 和证据不足拒答放进同一个离线系统。目标不是预测收益，而是验证一条研究事实
能否从界面回溯到文档、页码、chunk 和哈希。

\begin{itemize}
  \item 共同净值窗口内，002980 的累计变化最高（154.43\%），同时年化波动也最高
        （31.41\%）；003834 的最大回撤最深（-28.58\%）。
  \item 三组非对角收益相关性位于 0.774--0.891，说明样本期内三只基金方向相关，
        但路径和持仓披露仍有差异。
  \item 003834 的 C10 始终较高（51.99\%--59.20\%）；这只说明公开前十大占 NAV
        比例较高，不代表全部持仓高度集中。
  \item 同报告期公开前十大 CommonNAVShare 的样本最大值为
        16.55\%，出现在 2025Q4 的
        003834 / 002980；该指标不能解释为完整持仓重合。
  \item 冻结评测中开发题 10/10、保留题 5/5 端到端通过；保留题只运行一次，
        看过结果后未调参。
\end{itemize}

\callout{\textbf{核心边界：}系统是离线 TF-IDF 检索与模板化 Memo，不是完整
LLM RAG；评测题集小，15/15 不代表任意基金问题上的普遍准确率。}

\subsection{数据与文档处理}

真实研究数据来自基金管理人官方产品页、历史净值页、公告页和季度报告 PDF。
完整 PDF、完整提取文本、全量真实派生数据和原始响应只保存在本地忽略目录。

\begin{enumerate}
  \item 官方 PDF 按一基物理页提取，并清理重复页眉、页脚与断行。
  \item 每个 chunk 只能属于一份文档和一个物理页，保存
        \texttt{doc\_id}、\texttt{chunk\_id}、页码和 SHA-256。
  \item F4 共处理 175 个物理页、105,426 个清理后字符，
        形成 223 个单页 chunk。
  \item F5 索引 223 个 chunk，字符 gram 词表规模为
        38,033。
\end{enumerate}

\begin{figure}[H]
\centering
\includegraphics[width=\linewidth]{reports/figures/public_top10_overlap.png}
\caption{三组基金在同报告期的 CommonNAVShare}

跨基金比较严格限制在同一报告期。NameJaccard 使用披露名称精确交集除以并集；
CommonNAVShare 按股票代码识别共同股票，并对每只共同股票取两只基金 NAV 权重的
较小值后求和。

\begin{itemize}
  \item 003834 与 002980 在 2025Q4 的 CommonNAVShare 为 16.55\%，是样本最大值。
  \item 003567 与 002980 在 2026Q2 的公开前十大没有共同股票。
  \item 以上结论只覆盖公开前十大，不能写成完整持仓重合或组合穿透。
\end{itemize}

\section{检索、Memo 与拒答}

\subsection{检索基线}

系统在用户先选择基金和报告期后，使用中文字符 2--4 gram TF-IDF 与余弦相似度
检索。证据卡保留命中文本、分数、文档、物理页、chunk 和哈希。

\subsection{双阈值证据门槛}

回答必须同时满足最低最高分和最低查询 gram 覆盖率。门槛不足时，系统精确输出：

\begin{quote}
\color{coral}\bfseries 当前文档不足以回答该问题。
\end{quote}

通过门槛后，Memo 固定包含“已确认事实、原文证据、研究含义、当前无法确认的内容”
四段。事实部分只放入命中证据的短摘录，不能自由生成未引用结论。

\callout{\textbf{选择理由：}小语料下优先采用可解释、离线和稳定的检索基线。
不使用 LangChain、FAISS、外部 embedding、OpenAI API、DeepSeek API 或本地大模型。}

迭代；5 个保留题在模型、阈值、题目、gold 页和评测器冻结后只执行一次。

\section{局限、负结果与结论}

\subsection{关键局限}

\begin{itemize}
  \item 只有 3 只同一管理人旗下基金，报告和评测样本都较小。
  \item 官方报告存在模板变化；未披露行业项保留为空，不用零填充。
  \item TF-IDF 是词面检索，可能拒绝语义相关但用词不同的问题。
  \item 小型真实样例不提供完整上下文；正式研究必须返回官方报告核验。
  \item 系统不提供实时风控、交易信号、回测、组合优化或收益预测。
\end{itemize}

\subsection{结论}

本项目完成了从官方数据审计、结构化指标、单页 chunk、可解释检索、物理页 citation、
保守拒答、冻结评测到公开离线演示的完整链路。最重要的产出不是某个模型分数，而是
每个数字、引用和简历表述都有明确的结果文件、脚本、配置和数据版本。
