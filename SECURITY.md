# Security Policy

Do not post API keys, tokens, credentials, private fund PDFs, provider
responses, or local logs in public issues. Rotate a credential immediately if
it may have been exposed, then report the file path and category privately to
the maintainer without including the secret value.

The default service is local `MOCK_ONLY` and has no network or key requirement.
Online execution is intentionally disabled by default and must not be enabled
by placing credentials in a committed file.
